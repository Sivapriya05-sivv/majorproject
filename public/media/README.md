# Veo 3 Educational Video Storage

This directory holds the educational video files generated by the media team using Google Veo 3 for all 4 learning groups:
- `care-group/` (Modules 01 to 11)
- `primary/` (Modules 01 to 07)
- `secondary/` (Modules 01 to 09)
- `vocational/` (Modules 01 to 09)

Structure:
```
public/media/
├── care-group/
│   └── module-01/
│       └── lesson-01/
│           ├── main-concept.mp4
│           └── demonstration.mp4
├── primary/
│   └── module-01/lesson-01/
├── secondary/
│   └── module-01/lesson-01/
└── vocational/
    └── module-01/lesson-01/
```

When an MP4 video is not yet placed in a lesson folder, the video player seamlessly renders an Ollie animated placeholder with playback preview controls and Malayalam narration.
